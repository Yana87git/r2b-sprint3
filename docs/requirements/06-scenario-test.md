# シナリオテスト仕様書: 引合書整理エージェント

> Vモデル: システムテスト（右側）/ 対応する設計: ② 要件定義
> 5つの設計書（①〜⑤・`agent.md`）が固まった段階で、② の受入基準をもとに生成する。
> **Build した実アプリ**（モックではない）に対して手動で実行し、判定を記録する。

## 使い方（研修生向け）

1. Build した実アプリを起動する（前提環境を満たす）
2. シナリオを上から順に実行し、各ステップの期待結果と一致するか確認する
3. 判定欄に ☐Pass / ☐Fail を記録する（Fail はメモに事象を残す）
4. Fail は原因を **要件(②)・設計(③〜⑤・`agent.md`)・実装(Build)** のどこかに切り分けて修正する
5. 全シナリオ Pass ＝ 要件を満たしたことの証明

> **エージェントのシナリオ（TEST-05〜07・14〜18）は、トレース `backend/traces/{run_id}.jsonl` と突き合わせて判定する。** 観点は `agent.md` の完了条件・ツールの使い方・ガードレール・停止条件の4つ。

## 前提環境

| 項目 | 内容 |
| ---- | ---- |
| 対象 | Build した実アプリ（ローカル）。Frontend `http://localhost:3000` ／ Backend `http://localhost:8000` |
| 起動手順 | ターミナル1: `docker compose up -d`（PostgreSQL）／ ターミナル2: `cd backend && uv run uvicorn app.main:app --reload` ／ ターミナル3: `cd frontend && npm run dev` |
| 認証情報 | シーダーで作成した営業事務ロールの利用者（ユーザーID・パスワード）。ベテラン役は使わない（KPI4 は「ベテランに聞かずに」が条件） |
| テストデータ | `backend/tests/fixtures/` に置く（下表）。**実在の取引先の書類は使わない** |
| 初期状態 | 案件0件。`backend/traces/` は空。`backend/.env` に `ANTHROPIC_API_KEY` がある |
| 評価用の設定 | TEST-17・18 は停止条件を確かめるため、環境変数で `MAX_TURNS` / `INNER_TIMEOUT_S` を一時的に下げる（本番の値は `agent.md` の実行設定のとおり） |

### 用意するテストデータ

| # | ファイル | 中身 | 使うシナリオ |
|---|---------|------|------------|
| D1 | `normal_excel.xlsx` ＋ `normal_spec.pdf` | 明細12行・小計行あり・「3箱(1箱50本)」・「10月末」。PDF は追加品目1と材質の補足 | TEST-03・08〜13 |
| D2 | 4形式8件（Excel2・PDF2・Word2・メール本文2相当）。**うち2件は複数入力の案件**（Excel＋PDF ／ Word＋メール本文）、**うち2件は初見の書式**。**8件それぞれに既知の誤りを1件ずつ仕込む**（H2 が3件・H3 が3件・H1 が2件） | 仕込み方は `agent.md`「KPI8 のテスト書類の設計要件」に従う | TEST-05・06・07 |
| D3 | 欠落10件 | 納期または数量が欠けている引合書 | TEST-06 |
| D4 | `scanned.pdf` | テキストレイヤのないスキャン（手書き・FAX 由来） | TEST-15 |
| D5 | `greeting_mail.txt` | あいさつと依頼文だけで明細がないメール本文 | TEST-16 |
| D6 | `broken.pdf` | 破損して開けない PDF | TEST-14 |
| D7 | 拒否される入力一式 | `.docx` 以外の対応外拡張子（`.csv` など）・`old.xls`・21MB のファイル・11件目のファイル・合計50MB 超 | TEST-04 |

> **D7 のうち 21MB のファイルと合計50MB超の一式は、リポジトリに置かず、テスト実行時に生成する。** サイズ検査は中身を読まずに弾く処理なので、ダミーのバイト列でよい（例: `dd if=/dev/zero of=/tmp/big.pdf bs=1m count=21`）。
>
> `backend/tests/fixtures/` に置くと git の履歴に恒久的に残り、以後どのクローンでも 70MB 以上を毎回ダウンロードすることになる。あとで消しても履歴からは消えない。D1〜D6 と、D7 のうち小さいもの（対応外拡張子・`old.xls`・11件目のファイル）は、そのままリポジトリに置いてよい。
