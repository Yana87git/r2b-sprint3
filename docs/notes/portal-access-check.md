## 結論

このネットワークレベルでは、ポータルのホストには到達できる。ネットワーク遮断（EGRESS_BLOCKED）は起きていない。

ただし、読めるのはログイン画面の HTML までで、ポータルの中身（Sprint3 の提出物一覧など）は読めない。足りないのは**ネットワーク経路ではなく認証**。中身を読むには以下のいずれかが必要と考えられる:

- 認証済みセッション Cookie / トークンを付けてリクエストできる手段
- ログイン情報を使ってフォーム送信からセッションを確立できる手段（現在の WebFetch は認証付きリクエストに非対応）

なお WebFetch はクロスホストのリダイレクトを自動追跡しないため、リダイレクトを挟むページは都度 URL を指定し直す必要がある。
